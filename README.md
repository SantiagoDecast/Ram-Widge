# RamWidget

Liberador de RAM gratuito y portable para Windows 10/11.
Un solo .exe, sin instalación.

## ¿Qué hace?

- **Libera RAM al instante:** vacía working sets y purga la caché en espera de Windows.
- **Monitoreo en vivo:** RAM, CPU, GPU y disco, con temperaturas.
- **Cierra lo que te frena:** clic derecho sobre una app para cerrarla completa, incluidos sus procesos hijos.
- **Autolimpieza opcional:** se activa cuando la RAM supera el 80 %.
- **Modo barra compacta**, opacidad ajustable y modo "traspasar clics".
- Detecta GPUs NVIDIA, AMD e Intel (uso y VRAM).

## Descarga

Ve a [Releases](../../releases) y descarga `RamWidget.exe`.

## Uso

1. Ejecuta `RamWidget.exe`.
2. Pulsa el botón de liberar RAM o activa la autolimpieza.

## Antivirus

Algunos antivirus pueden marcarlo al primer uso por la forma en que gestiona la memoria y los procesos. Es un falso positivo. Análisis en VirusTotal: https://www.virustotal.com/gui/file/052c35c4d532a478fe6e8176b1e5b2b4fd86c3c0034d5b152a0336ecce409857
